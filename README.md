# Liar’s Dice Online

Этап 1. Движок правил `classic-wilds-v1` для 2–5 игроков.

## Запуск проверок

Требуются Node.js 24 и Corepack. Версия pnpm закреплена в `package.json`.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm test
corepack pnpm typecheck
corepack pnpm build
```

## Использование модуля

Пакет `@liars-dice/game-rules` собирается в `packages/game-rules/dist`.
Передайте в `startMatch` места в порядке хода, ID начинающего,
готовые руки и текущее серверное время в миллисекундах.
`applyAction` применяет заявку или оспаривание и возвращает новое состояние
либо код отказа. `expireTurn` обрабатывает истёкший ход.
`advanceRound` открывает следующий раунд после вскрытия с переданными руками.
`legalBids` возвращает варианты для формы заявки.

Движок хранит все руки. На следующих этапах сервер должен строить отдельный
снимок для каждого участника перед передачей состояния по сети.

## Результат проверки этапа

Vitest выполнил 23 теста. Покрыты сценарии G01–G11, перебор заявок
для 2–25 кубиков в обоих режимах и завершение симулированных партий
на 2, 3, 4 и 5 игроков. Проверка типов и сборка прошли.


## Этап 2. Регистрация и вход

Понадобятся Node.js 24, Corepack и Docker с Compose. В корне проекта выполните:

```sh
corepack pnpm install --frozen-lockfile
cp .env.example .env
```

Сгенерируйте секрет командой `openssl rand -hex 32` и вставьте результат
в `BETTER_AUTH_SECRET` в файле `.env`.

```sh
docker compose up -d --wait
corepack pnpm migrate
corepack pnpm dev
```

Откройте [Liar’s Dice](http://localhost:3000) и нажмите «Создать аккаунт».
Для проверки подойдёт вымышленный адрес, например `anna@example.test`.
Откройте [Mailpit](http://localhost:8025), перейдите по ссылке из письма
подтверждения и войдите. Второй аккаунт можно проверить в приватном окне.
Для проверки восстановления выйдите и нажмите «Восстановить пароль».
Все письма локальной конфигурации поступают в Mailpit.

Прямая ссылка вида `http://localhost:3000/r/ABCD2345` сохраняется
при регистрации, подтверждении и входе. Занятие места по приглашению
появится на этапе 3. При смене адреса запуска настройте
`BETTER_AUTH_URL` на фактический внешний адрес приложения.
Для HTTPS сервер выставляет cookie с флагом `Secure`.

### Проверки аккаунтов

После миграции выполните с остановленным приложением:

```sh
corepack pnpm build
corepack pnpm --filter @liars-dice/web exec playwright install chromium
corepack pnpm test:auth
```

Playwright запускает приложение на время теста. Можно указать
`CHROMIUM_PATH`, чтобы использовать установленный Chromium, или передать
`APP_URL`, чтобы проверить уже запущенное приложение. Сценарий проходит
регистрацию и подтверждение двух аккаунтов в отдельных контекстах,
проверяет возврат к ссылке, уникальность ника, вход, выход и отзыв
старой сессии после сброса пароля. PostgreSQL и Mailpit должны быть запущены.
